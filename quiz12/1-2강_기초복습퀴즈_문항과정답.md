# 1·2강 기초 복습 퀴즈 문항과 정답

문제 슬라이드 다음에 정답·해설 슬라이드가 이어집니다.

## 1강 · 스마트팩토리에서 제조AX로

**1. 한국은 근로자 1만 명당 로봇 수가 세계 1위다. 그런데도 1강에서 한국 제조업의 어두운 면으로 짚은 것은?**

① 공장 로봇이 부족하다  
② 수출이 계속 줄고 있다  
③ 제조업 비중이 OECD에서 가장 낮다  
④ 시간당 노동생산성이 낮고 제조 인력이 고령화되고 있다

정답: ④ 시간당 노동생산성이 낮고 제조 인력이 고령화되고 있다  
해설: 밝은 면: 로봇 밀도 세계 1위, 수출 역대 최대, 제조업 비중 OECD 2위 / 어두운 면: 시간당 노동생산성 OECD 24위, 제조업 60세 이상 17.5% / 로봇과 설비를 더 사는 것만으로는 부족 → 공장이 똑똑해져야 한다  
복습: 1강 2장 · 한국 제조업의 밝은 면과 어두운 면

**2. 어떤 제품을 언제 몇 개 만들지 지시하고, 생산 실적과 품질 이력을 기록하는 운영 층의 시스템은?**

① MES (제조 실행 시스템)  
② PLC (설비 제어기)  
③ 로봇 제어기  
④ 데이터 플랫폼

정답: ① MES (제조 실행 시스템)  
해설: 현장 장치(센서, 모터, 로봇, 카메라) → 설비 제어(PLC, 로봇 제어기) / 운영: MES가 생산을 지시하고 실적·품질 이력을 기록 / 그 위에 경영 층 / 데이터 플랫폼은 모든 층을 관통해 데이터를 모으는 역할  
복습: 1강 5장 · 스마트팩토리의 계층 구조

**3. 디지털 트윈은 실제 설비의 센서 데이터와 연동되므로, 생산 라인을 멈추지 않고 가상 공장에서 먼저 변경안을 시험해 볼 수 있다.** (O/X)

정답: O  
해설: 3차원 형상뿐 아니라 물리 모델과 실시간 센서 데이터를 담은 가상의 쌍둥이 / 짓기 전에 가상으로 짓고, 돌려 보고, 고친다 / 예: BMW 데브레첸 공장, 양산 2년 전부터 가상 공장에서 생산  
복습: 1강 6장 · 스마트팩토리를 만드는 여섯 가지 기술

**4. 정부가 보급한 스마트공장의 약 75%는 아직 '기초 단계'에 머물러 있다. 기초 단계의 한계로 옳은 것은?**

① 센서와 설비가 네트워크에 전혀 연결되어 있지 않다  
② 로봇이 하나도 도입되지 않았다  
③ 생산 정보를 디지털로 기록하는 데 그쳐, 데이터가 의사결정으로 이어지지 않는다  
④ AI가 공정을 제어하지만 사람이 결과를 확인하지 않는다

정답: ③ 생산 정보를 디지털로 기록하는 데 그쳐, 데이터가 의사결정으로 이어지지 않는다  
해설: 2014년부터 3만여 기업에 보급, 도입 기업 생산성 30% 향상 / 그러나 75.5%는 생산 정보를 디지털로 기록하는 기초 단계 / 모인 데이터로 판단하는 것이 다음 걸음, 곧 제조AX  
복습: 1강 7장 · 스마트공장 3만 개, 그러나 75%는 기초 단계

**5. DX(디지털 전환)에서 확대되는 AX(AI 전환)의 핵심은?**

① 센서를 더 달아 데이터를 더 많이 모으는 것  
② AI가 데이터를 분석해 답을 제안하거나 설비를 직접 제어하는 것  
③ 실시간 대시보드로 공장 상태를 사람에게 보여 주는 것  
④ 모든 설비 데이터를 클라우드에 저장하는 것

정답: ② AI가 데이터를 분석해 답을 제안하거나 설비를 직접 제어하는 것  
해설: DX(디지털 전환): 데이터를 모아 공장을 자동화하는 단계 / ①③④는 DX에 해당 / AX(AI 전환): AI가 주변 환경, 데이터 및 상황들을 인지하고 판단하는 지능화 및 자율화 / 대표 분야: 품질 검사(3강), 고장 예측과 공정 최적화(4강)  
복습: 1강 8장 · 제조AX: 보이게 하는 것에서 스스로 판단하게 하는 것으로

**6. 독일 지멘스 암베르크 공장의 품질 수준은 99.9989%다. 제품을 100만 개 만들면 불량은 약 몇 개인가?**

① 약 1개  
② 약 11개  
③ 약 110개  
④ 약 1,100개

정답: ② 약 11개  
해설: 불량률 = 100% − 99.9989% = 0.0011% / 100만 개 × 0.000011 = 약 11개 / PLC 같은 제어 기기를 약 1,000종 만들면서도 지키는 품질 수준  
복습: 1강 12장 · 해외 사례: AI 팩토리와 다크팩토리

**7. 정부가 꼽은 로봇 핵심 부품인 액추에이터, 로봇 손, 센서는 주로 소프트웨어 분야의 기술이다.** (O/X)

정답: X  
해설: 액추에이터(구동기), 로봇 손, 센서는 모두 기계제어 분야의 기술 / AI가 아무리 똑똑해도 센서가 제대로 재지 못하고 로봇이 정밀하게 움직이지 못하면 공장에서 쓸모가 없다 / AI가 판단하고, 기계와 제어가 그 판단을 실현한다  
복습: 1강 14장 · 정리 (AI 팩토리: AI+전공도메인 융합 필요)

## 2강 · 제조AX와 AI 팩토리, 지금 어디까지 왔나

**8. 불을 끄고도 돌아간다는 '다크 팩토리'에 대해 2강이 강조한 핵심은?**

① 조명을 끄므로 에너지를 크게 아낀다  
② 사람보다 로봇이 많다  
③ 운영 인력이 필요 없으므로 엔지니어도 필요 없다  
④ 공장이 스스로 보고, 판단하고, 움직인다

정답: ④ 공장이 스스로 보고, 판단하고, 움직인다  
해설: 사람이 거의 없어 조명이 필요 없는 공장 / 샤오미 베이징 공장: 자동화율 81%, 약 6초마다 스마트폰 1대 / 핵심은 로봇의 수가 아니라 스스로 보고·판단하고·움직이는 것  
복습: 2강 2장 · 불을 끄고도 돌아가는 공장, 다크 팩토리

**9. 2강은 공장 진화를 자동화 → 디지털화 → 지능화 → 자율화의 네 단계로 나눴다. 지능화와 자율화를 가르는 차이는?**

① AI가 내린 판단을 스스로 실행까지 하는가  
② 센서로 공장 데이터를 수집하는가  
③ PLC로 정해진 동작을 반복하는가  
④ 사람이 대시보드로 공장을 보는가

정답: ① AI가 내린 판단을 스스로 실행까지 하는가  
해설: 디지털화는 눈, 지능화는 두뇌(AI가 판단), 자율화는 손(판단을 실행) / 1강의 '지능화'를 2강에서는 판단과 실행 두 단계로 나눠 본 것 / 자율화: 로봇이 상황에 맞게 동작을 바꾸고 생산 계획도 스스로 조정  
복습: 2강 6장 · 공장 진화의 네 단계: 누가 판단하는가

**10. 뉴스의 'AI 팩토리'는 AI를 만드는 거대한 컴퓨터 센터를 뜻하기도 하고, AI로 운영되는 제조 공장을 뜻하기도 한다.** (O/X)

정답: O  
해설: AI를 만드는 공장: 데이터를 넣으면 AI 모델이 나오는 컴퓨터 센터 / AI로 움직이는 공장: AI로 운영되는 실제 제조 공장 / 둘은 연결된다: 삼성 · 현대차가 AI 연산용 반도체(GPU) 5만 장으로 자기 공장의 두뇌를 만든다  
복습: 2강 7장 · 'AI 팩토리'의 두 가지 의미

**11. 엔지니어가 자연어로 설명하면 AI가 설비제어 프로그램(PLC 등)을 작성하고 설계·생산 계획·정비 업무까지 처리하는 기술은?**

① 엣지 AI  
② 피지컬 AI  
③ 산업 AI 에이전트  
④ 디지털 트윈

정답: ③ 산업 AI 에이전트  
해설: 예: 지멘스 산업용 코파일럿, 자연어 설명 → PLC 코드 / 도우미를 넘어 설계 · 생산 계획 · 정비까지 처리하는 AI 에이전트 / 숙련공의 노하우(암묵지)를 데이터로 만들어 AI에게 가르친다  
복습: 2강 8장 · 산업 AI 에이전트: 말로 설명하면 AI가 일한다

**12. 로봇을 디지털 트윈 속 가상 공장에서 먼저 학습시킨 뒤, 실제 공장으로 옮기는 방법은?**

① 엣지 AI  
② 심투리얼 (Sim-to-Real)  
③ 피지컬 AI  
④ 산업 AI 에이전트

정답: ② 심투리얼 (Sim-to-Real)  
해설: 현실에서 수천 번 넘어뜨리며 가르치면 느리고 위험하다 / 디지털 트윈 = 로봇의 훈련장, 가상 공장에서 리허설 / 예: 삼성전자, 엔비디아 아이작 심에서 로봇을 먼저 훈련·검증  
복습: 2강 9장 · 디지털 트윈과 시뮬레이션

**13. BMW 공장의 휴머노이드 실증에서 가장 자주 고장 난 곳은 로봇의 팔뚝이었다. 이 사례가 보여 주는 피지컬 AI의 관건은?**

① 더 큰 생성형 AI 모델  
② 더 빠른 클라우드 서버  
③ 더 많은 학습 데이터  
④ 구동기, 감속기, 센서 같은 기계 부품과 제어 기술

정답: ④ 구동기, 감속기, 센서 같은 기계 부품과 제어 기술  
해설: 피지컬 AI: AI가 로봇의 몸을 얻어 현실에서 보고 직접 움직이는 것 / 예: 피규어 AI의 BMW 실증, 현대차그룹 아틀라스 2028년 조지아 공장 투입 계획 / 몸을 만들고 움직이는 것은 기계와 제어의 몫  
복습: 2강 10장 · 피지컬 AI와 휴머노이드: AI가 몸을 얻다

**14. 로봇이 판단할 때마다 멀리 있는 서버와 통신하면 네트워크 지연 때문에 로봇이 멈추거나 사고가 날 수 있다. 설비와 로봇 안의 AI 칩으로 현장에서 바로 판단하게 해 이 문제를 줄이는 기술은?**

① 생성형 AI  
② 디지털 트윈  
③ 엣지 AI  
④ 산업 AI 에이전트

정답: ③ 엣지 AI  
해설: 멀리 있는 서버에 물으면 네트워크 지연 → 로봇이 멈추거나 사고 / 엣지 AI: 설비 · 로봇 안의 AI 칩이 현장에서 즉시 판단 / 바탕은 데이터: 제조 AI 프로젝트 시간의 상당 부분이 데이터 준비  
복습: 2강 11장 · 엣지 AI와 산업 데이터: 현장에서 바로 판단한다

**15. AI 팩토리 시대에는 AI 소프트웨어만 잘 다루면 되므로, 기계와 제어 지식의 중요성은 줄어든다.** (O/X)

정답: X  
해설: 디지털 트윈엔 동역학, 휴머노이드엔 모터·감속기·센서 설계와 제어, AI가 쓴 PLC 코드 검증엔 자동제어 / AI는 두뇌, 기계는 몸, 제어는 그 몸을 움직이는 기술 / 가장 부족한 인재: 기계와 제어를 알고 AI까지 다루는 엔지니어  
복습: 2강 15장 · 기계제어공학과의 연결
