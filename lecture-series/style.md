# 제조 AX 혁신과 공학진로 강의 시리즈 공통 PPT 스타일 (1~4강)

- 캔버스: pptxgenjs LAYOUT_16x9 (10 x 5.625 in)
- 글꼴: 제목·본문 모두 "맑은 고딕" (Malgun Gothic)
- 색상 (hex)
  - 기본 어두운색 dk1/텍스트: 1E2A32 (그래파이트)
  - 강조 accent1: F28C28 (산업용 오렌지)
  - 보조 accent2: 2A9D8F (틸)
  - 보조 accent3: 5B6770 (중간 회색, 캡션)
  - 밝은 배경 lt1: FFFFFF / 카드 배경 lt2: F2F4F5
- 표지·구간 구분·마지막 슬라이드: 배경 1E2A32, 흰 글씨, 오렌지 강조
- 본문 슬라이드: 흰 배경. 제목 x=0.5 y=0.3 w=9 h=0.6, 24pt 굵게, 1E2A32, 왼쪽 정렬
  - 제목 위 작은 구간 라벨(예: "1부 · 공장은 왜 바뀌고 있나") 11pt 오렌지, y=0.12
- 바닥글: 왼쪽 "제조 AX 혁신과 공학진로 · N강" 9pt 5B6770 (x=0.5, y=5.25), 오른쪽 쪽번호
- 표지 발표자 표기: "한동대학교 기계제어공학부 김영근 교수"
- 모티프: 오렌지 원 안의 흰 아이콘 (react-icons), 카드는 F2F4F5 배경 + 옅은 그림자, 테두리 줄무늬 없음
- 본문 14pt 이상, 큰 숫자 콜아웃 32~40pt 오렌지 굵게
- 발표자 노트 = 대본 전문
- 참고 구현: lecture1_build_reference.js (1강 pptxgenjs 생성 스크립트, 마스터·카드·아이콘 헬퍼 포함)

## 사진·그림 출처 표기 규칙
- 라이선스가 확인된 이미지만 사용 (위키미디어 공용의 CC BY / CC BY-SA / 퍼블릭 도메인, 기업 보도자료 사진은 보도용 허용 여부 확인)
- 사진 바로 아래 또는 슬라이드 하단 왼쪽에 8pt 회색(5B6770)으로: "사진: 작성자, 라이선스, Wikimedia Commons"
- 사진은 둥근 모서리 없이 직사각형, 테두리 없음. 가능하면 카드 높이에 맞춰 잘라 배치(sizing: cover)
- 사용한 이미지 목록(파일명, 원본 URL, 작성자, 라이선스)은 lectureN/image_credits.md 에 기록
