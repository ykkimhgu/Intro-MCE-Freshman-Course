# 3·4강 기초 복습 퀴즈 문항과 정답

문제 슬라이드 다음에 정답·해설 슬라이드가 이어집니다.

## 3강 · 영상 기반 품질검사

**1. 같은 불량이라도, 언제 발견할 때 비용이 가장 적게 들까요?**

① 공정 중  
② 출하 직전  
③ 고객에게 간 뒤  
④ 리콜이 결정된 뒤

정답: ① 공정 중  
해설: 1-10-100 법칙: 공정 중 1 → 출하 직전 10 → 고객 손에서 100 / 정확한 배수보다 '늦을수록 급격히 커진다'가 핵심 / 그래서 공정 고비마다 검사를 두고 빠짐없이 본다  
복습: 3강 2장 · 왜 품질검사인가

**2. 불량품을 정상으로 보고 그대로 통과시키는 오류를 무엇이라고 할까요?**

① 미검출  
② 과검출  
③ 정밀도  
④ 분할

정답: ① 미검출  
해설: 미검출 = 놓침: 불량이 고객에게 → 리콜, 고객 피해 / 과검출 = 오경보: 정상품을 불량으로 → 버려지는 제품, 재검사 / 현장은 미검출을 먼저 막는다  
복습: 3강 3장 · 품질검사의 핵심 개념

**3. 규칙 기반 머신비전은 스크래치나 얼룩처럼 모양이 제멋대로인 불량을 찾는 데 특히 강하다.** (O/X)

정답: X  
해설: 규칙 기반: 사람이 정한 규칙·임계값으로 판정 / 치수 측정처럼 정답이 분명한 일에 강함 / 불규칙한 불량은 규칙으로 표현하기 어려움 → 딥러닝의 등장  
복습: 3강 4장 · 기술의 발전

**4. 딥러닝 검사가 규칙 기반 머신비전과 가장 다른 점은?**

① 사람이 판정 규칙을 하나하나 정해 준다  
② 불량 사진을 보고 컴퓨터가 스스로 판별법을 배운다  
③ 카메라 없이 검사한다  
④ 사람이 눈으로 직접 본다

정답: ② 불량 사진을 보고 컴퓨터가 스스로 판별법을 배운다  
해설: 규칙 기반: 사람이 규칙을 짠다 / 딥러닝: 사진을 많이 보여 주면 컴퓨터가 스스로 배운다 / 대신 불량 사진이 많이 필요하다  
복습: 3강 4장 · 기술의 발전

**5. 같은 스크래치라도 조명을 비추는 방향에 따라 카메라에 또렷하게 보이기도 하고, 사라지기도 한다.** (O/X)

정답: O  
해설: 빛을 비스듬히 비추면 또렷, 정면에서 비추면 사라질 수 있다 / 현장에서는 '좋은 영상이 검사 성능의 절반'이라고 할 정도 / 카메라·조명 설계 = 광학과 센서의 영역  
복습: 3강 5장 · 영상검사 시스템의 구성

**6. 불량 사진이 거의 없을 때, 정상 사진만 배우고 정상과 다른 것을 찾아내는 방법은?**

① 이상탐지  
② 객체 검출  
③ 규칙 기반 머신비전  
④ 육안 검사

정답: ① 이상탐지  
해설: 잘 관리되는 공장일수록 불량 사진이 귀하다 / 이상탐지: 정상의 모습만 기억 → 처음 보는 모양이면 경보 / 예: 지멘스 인스펙토는 정상 제품 20개 정도로 학습  
복습: 3강 7장 · 정상만으로 배우는 이상탐지

**7. 현대차그룹 싱가포르 혁신센터(HMGICS)에서 조립 품질을 촬영해 검사하는 것은?**

① 천장에 고정된 카메라  
② 네 다리로 걷는 로봇 스팟  
③ 드론  
④ 숙련 작업자의 육안

정답: ② 네 다리로 걷는 로봇 스팟  
해설: 스팟이 조립 부위로 걸어가 촬영 → 비전 AI가 판정 / 검사 영역 38개, 정확도 99% 이상 (현대차그룹, 2023) / 로봇 제어 + 비전 AI = 기계제어공학의 종합 예제  
복습: 3강 11장 · 현대차 HMGICS

## 4강 · 고장 진단·예측과 공정 최적화

**8. 센서로 설비의 실제 상태를 재고, 고장 징후가 보일 때 미리 정비하는 방식은?**

① 사후정비  
② 예방정비  
③ 예지보전  
④ 공정 최적화

정답: ③ 예지보전  
해설: 사후정비: 고장 난 뒤 수리 / 예방정비: 정해진 주기마다 교체 / 예지보전: 상태를 재고 징후가 보이면 정비  
복습: 4강 3장 · 정비 전략의 진화

**9. 사후정비는 고장이 나기 전에 정해진 주기마다 부품을 미리 교체하는 방식이다.** (O/X)

정답: X  
해설: 사후정비 = 고장이 난 뒤에 고친다 → 갑작스러운 정지, 안전 사고 / 정해진 주기마다 교체하는 것은 예방정비 / 발전 순서: 사후정비 → 예방정비 → 예지보전 → 처방적 정비  
복습: 4강 3장 · 정비 전략의 진화

**10. 회전하는 기계의 상태를 읽기 위해 가장 널리 쓰는 센서 신호는?**

① 진동  
② 제품의 색깔  
③ 공장 조명의 밝기  
④ 하루 생산 대수

정답: ① 진동  
해설: 회전 기계는 늘 진동하고, 부품이 손상되면 진동의 모양이 달라진다 / 진동 외에 모터 전류, 초음파, 열화상도 함께 쓴다 / → 동역학, 기계진동  
복습: 4강 5장 · 계측 및 신호처리

**11. 시간에 따라 출렁이는 진동 신호를, 어떤 주파수 성분이 섞여 있는지로 바꿔 보는 방법은?**

① FFT (푸리에 변환)  
② PID 제어  
③ 강화학습  
④ 머신비전

정답: ① FFT (푸리에 변환)  
해설: FFT: 시간 영역 신호 → 주파수 영역 스펙트럼 / 베어링에 흠이 생기면 결함 주파수에 봉우리가 솟는다 / 봉우리 위치로 어느 부품이 아픈지 짚어낸다  
복습: 4강 5장 · 계측 및 신호처리

**12. '지금 어디가 고장인가'가 아니라 '고장까지 얼마나 남았나'를 묻는 단계는?**

① 진단  
② 예지  
③ 데이터 획득  
④ 사후정비

정답: ② 예지  
해설: 진단: 지금 정상인가, 어디가 아픈가 (현재) / 예지: 고장까지 얼마나 남았나, 잔여 유효 수명 (미래) / PHM: 데이터 획득 → 신호처리 → 진단 → 예지 → 의사결정  
복습: 4강 4장 · PHM의 다섯 단계

**13. 공정 최적화란 무엇일까요?**

① 품질·생산량·에너지에서 가장 좋은 결과를 내는 공정 조건을 찾는 것  
② 고장 난 설비를 수리하는 것  
③ 제품의 사진을 찍어 불량을 고르는 것  
④ 공장을 새로 짓는 것

정답: ① 품질·생산량·에너지에서 가장 좋은 결과를 내는 공정 조건을 찾는 것  
해설: 입력: 온도 · 압력 · 속도 · 원료 투입량 / 결과: 품질 · 생산량 · 에너지 / AI가 결과를 예측하고 가장 좋은 입력을 찾아 제어한다 (예: 포스코 스마트 고로)  
복습: 4강 9장 · 공정 최적화의 네 가지 접근
